# תוכן האתר

כאן נמצא כל הטקסט של האתר: תיקייה לכל שפה (`he`, `en`, `de`), וקובץ לכל עמוד.
כדי לשנות טקסט באתר, משנים אותו כאן בלבד.

## איך כתובים קובץ

```
---
kicker: שורה קטנה מעל הכותרת
---

## כותרת הקטע {#מזהה}

פסקה ראשונה.

פסקה שנייה.

> פסקה שמתחילה ב־> מוצגת כציטוט מודגש.
```

- **בין הקווים `---` בראש הקובץ** יש פרטים קצרים (שם, שורת פתיח וכו'), בפורמט `שם: ערך`.
- **`## `** פותח קטע חדש עם כותרת. ה־`{#מזהה}` בסוף הכותרת לא מוצג באתר; הוא אומר לאתר איפה להציב את הקטע. לא משנים ולא מוחקים אותו.
- **שורה ריקה** מפרידה בין פסקאות. שורה חדשה בלי שורה ריקה נשארת באותה פסקה, בשורה חדשה.
- **`>` בתחילת פסקה** הופך אותה לציטוט מודגש.
- **`<!-- ... -->`** הערה פנימית, לא מוצגת באתר.
